## 一、模考暴露的问题（6.3 2022 国 B 真题）

### P8800 卡牌 — 🚨 二分方向又反了！

```
我写的（错）：        正确写法：
check可行 → r=mid+1   check可行 → l=mid+1（抬高下界找更大）
check不行 → l=mid-1   check不行 → r=mid-1（压低上界找更小）
```

**死循环原理**：可行时 `r = mid+1`，但如果 `mid+1 == r`（本来 r 就没变），那 r 原地踏步，`while(r>=l)` 永远出不去。

**口诀（考试前默念 3 遍）**：
> 可行 → **左**移 → `l = mid + 1`（下界抬高，去找更大的）
> 不可行 → **右**移 → `r = mid - 1`（上界压低，去找更小的）

**二分已经是第三次犯了（P2678 → P3853 → P8800），事不过三，不能再有第四次。**

### P8805 机房 — 忘了判祖先关系

```cpp
// 对齐深度后必须加这行！
if (p == q) return p;  // 一个节点是另一个的祖先
```

忘了这一行 → 祖先关系的查询全挂。LCA 倍增板子对齐深度后的这行 `if(u==v) return u` 不是可选的，是必须的。

### P8803 费用报销 — 三个经典错误

1. **cmp 没 return** → 排序无效（编译不报错，最隐蔽）
2. **不选 i 时跳过头** → `dp[nex[i]][j]` 应改为 `dp[i-1][j]`
3. **`if(j > v)`** → 丢了等于号，刚好买得起的不让买

## 二、跨题高频重复错误（考场上一定会再遇到）

### 🚨 二分方向（3 次：P2678 / P3853 / P8800）

**现状**：三次中两次是方向反了，一次是 mid 公式写死。

**考试对策**：写完二分后，在草稿纸上走一遍 `n=3` 的小样例验证方向。

### 🚨 运算符优先级（3 次：P3865 / P3379 / P3379 又）

```
1 << j - 1    → 实际是 1 << (j-1)    // - 优先级高于 <<
1 << j > 5    → 实际是 1 << (j > 5)  // > 优先级高于 <<
```

**考试对策**：凡是 `1<<` 后面跟任何运算符，**一律加括号** → `(1 << j)`。

### 🚨 数组第二维越界（2 次：P3379 / P8805）

```cpp
int up[N][20];  // 列 0~19，共 20 列
for (int j = 1; j <= 20; j++)  // ❌ 访问了列 20！
for (int j = 1; j < 20; j++)   // ✅
```

**考试对策**：声明 `int up[N][20]` 后立刻在旁边注释 `// 0~19`，循环写 `< 20`。

### 🚨 LCA 边界遗漏（2 次：P3379 / P8805）

LCA 板子的三个"必须"：
```cpp
// 1. 必须设根哨兵
up[root][0] = root;

// 2. 对齐后必须判等
if (u == v) return u;

// 3. 跳完后必须再判一次
if (u == v) return u;  // 两节点在同一路径上
```

## 三、考前 48 小时核心清单

### 写代码时的 5 秒检查（每条代码写完扫一遍）

```
□ 所有 << 运算符加了括号吗？          → (1 << j)
□ 所有 sum/product 是 ll 吗？         → ll ans = 0;
□ 数组大小 = 题目最大 n + 10 吗？     → const int N = 5e5 + 10;
□ 并查集合并是改根不是改节点吗？       → fa[find(x)] = find(y)
□ 二分 check 可行时 l=mid+1 吗？     → 口诀确认
```

### 编译通过但答案不对 → 优先排查

1. **排序的 cmp 有没有 return？**（P8803）
2. **sort 传的是地址还是值？**（P1803）
3. **优先队列是小根堆吗？**（Dijkstra）
4. **树状数组读的是 tree 不是原数组？**（P3374）
5. **邻接表是 `vector<pair<int,int>> G[N]` 不是 `vector<...> G(n+1)`？**（P3371）

### 写完 LCA 必查清单

```
□ up[root][0] = root（根哨兵）
□ 第二维循环 j < LOG（不是 <=）
□ 深度对齐后 if(u == v) return u
□ 倍增跳完后 if(u == v) return u
□ 1 << j 都加了括号
```

### 写完 Dijkstra 必查清单

```
□ 小根堆 greater<pair<int,int>>
□ push({dis[v], v}) 在 if 里面
□ 不可达点输出要判断（不能直接输出 0x3f3f3f3f）
□ 两次 Dijkstra 之间 memset vis
□ 邻接表 G1, G2 别用混
```

## 四、按错误类型排优先级

### 致命级（直接 0 分）— 考场上必须杜绝

| 错误 | 口诀 |
|------|------|
| 二分方向反 | 可行左移（l 往右），不可行右移（r 往左） |
| 并查集改节点 | `fa[find(x)] = find(y)` 不是 `fa[x] = y` |
| 树状数组读原数组 | query 里加的是 `tree[x]` 不是 `a[x]` |
| Dijkstra push 在 if 外面 | 堆爆炸 → 内存超限 |
| 数组越界 | 开 n+10，第二维 < LOG |

### 致残级（丢部分分）— 考场上高度警惕

| 错误 | 口诀 |
|------|------|
| int 溢出 | 求和/乘积/前缀和 → ll |
| 边界遗漏（=号、+1/-1） | 写完代码逐行扫 if/for 条件 |
| 初始化缺失 | 板子默写包含初始化行 |
| 运算符优先级 | 1<< 永远加括号 |
| cmp 没 return | 排序的 cmp 第一行就是 `return` |

### 皮外伤（丢小分/调试耗时）

| 错误 | 对策 |
|------|------|
| endl 超时 | 全程 `'\n'`，只在交互题用 endl |
| C++17 结构化绑定 | 用 `.first` `.second` |
| 变量名遮蔽 cout | 不用标准库名做变量名 |
| 单引号 vs 双引号 | 字符串永远是 `"..."` |
