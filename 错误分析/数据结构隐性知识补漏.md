## 一、树的那些"理所当然"的性质

### 1.1 树的等价定义（你刚学会的）

```
以下四个说法是等价的，满足任意两个就能推出另外两个：
① n 个节点，n-1 条边
② 连通（任意两点可达）
③ 无环
④ 任意两点之间有且仅有一条简单路径  ← 你刚知道的这条
```

**这意味着什么？** 看到题目说 "n 个点 n-1 条边连通"，立刻反应：
- 这是一棵树
- 两点路径唯一 → 路径问题 = LCA 问题
- 加一条边 = 恰好形成一个环
- 删一条边 = 图不连通（分成两棵子树）

### 1.2 树的直径

**定义**：树中最远两点之间的距离（经过的边数或边权和）。

**求法**（两次 BFS/DFS）：
```
第一次：从任意点出发，找到最远点 u
第二次：从 u 出发，找到最远点 v
→ (u, v) 就是直径的两个端点
```

**性质**：树上任意点到其他点的最远点，一定是直径两端点之一。这个性质 2023 景区导游题间接用到了。

### 1.3 树的重心

**定义**：删掉这个点后，剩下的最大连通块最小。

**求法**：DFS 算子树大小，`max_sub = max(max_sub, n - size[v])`，取 max_sub 最小的节点。

**性质**：重心最多两个；删掉重心后每个连通块大小 ≤ n/2。

> B 组国赛还没直接考过重心，但知道这个概念能帮你理解树形 DP 的"选根"问题。

### 1.4 树的 DFS 序 / BFS 序

- **DFS 序**：DFS 遍历时第一次访问每个节点的顺序。**一棵子树在 DFS 序中是一段连续区间。**
- 这是树剖和很多树上问题的底层原理。LCA 倍增建 `up` 表时用的 BFS 也是类似的道理——按深度分层。

### 1.5 为什么 LCA 用倍增而不是一步一步跳？

```
暴力：u 一步一步往上跳到根，O(n)
倍增：预处理每个点往上 1, 2, 4, 8... 步的祖先，跳的时候 O(log n)

核心思想叫"二进制拆分"：任何整数都可以拆成若干个 2 的幂之和
比如跳 13 步 = 8+4+1 步（13 = 1101₂）
```

这个"任何数都能二进制拆分"的思想不只用在 LCA，还用在快速幂、ST 表、树状数组。

## 二、前缀和与差分的"微积分"直觉

### 2.1 前缀和 = 积分，差分 = 导数

```
原数组 a[i]        ← 你有的数据
差分 diff[i]       ← 相当于 a 的"变化率"（导数）
前缀和 pre[i]      ← 相当于 a 的"累积量"（积分）

差分做前缀和 = 还原原数组（积分还原）
前缀和做差分 = 还原原数组（求导还原）
两者互为逆运算
```

### 2.2 为什么差分能处理"多次区间修改"？

```
区间 [l, r] 加 x：
  diff[l] += x      → 从 l 开始，变化率 +x
  diff[r+1] -= x    → 从 r+1 开始，变化率恢复

还原（前缀和）后：a[l..r] 都加了 x，a[r+1..] 不受影响
```

**直觉**：差分记录的是变化的"开关"——在 l 处打开 (+x)，在 r+1 处关闭 (-x)。

### 2.3 二维差分（你可能没接触过）

```
子矩阵 (x1,y1) 到 (x2,y2) 加 x：
  diff[x1][y1] += x
  diff[x2+1][y1] -= x
  diff[x1][y2+1] -= x
  diff[x2+1][y2+1] += x

还原：对 diff 做二维前缀和
```

画个图理解：四个角分别标记 +x 和 -x，前缀和扫过去时影响恰好落在矩形内。

### 2.4 树上差分（你在砍树见过，但可能不知道为什么这么写）

```
边差分：路径 (u, v) 上所有边 +x
  diff[u] += x
  diff[v] += x
  diff[lca] -= 2x        ← 为什么减 2x？
                         因为 u 往上到 lca、v 往上到 lca 各加了 x
                         lca 往上不受影响，所以要抵消掉两次

点差分：路径 (u, v) 上所有点 +x
  diff[u] += x
  diff[v] += x
  diff[lca] -= x
  diff[parent[lca]] -= x ← lca 自己也要 +x，所以只减一次
                         然后 lca 的父节点往上不受影响
```

## 三、图论中那些"不说但你该知道"的结论

### 3.1 最小生成树（MST）的关键性质

> **性质**：MST 中，任意两点之间路径上的最大边权，是所有连接这两点的路径中最大边权最小的。

这个性质叫 **MST 的瓶颈性质**（minimax path）。很多"最小化路径最大边"的题都是 MST 变体。

### 3.2 Dijkstra 为什么不能处理负权边？

```
Dijkstra 的核心假设：当前距离最小的点，其距离已经"确定"了。
但如果存在负权边，后面可能通过一条负边绕路，让距离更小。
→ "已确定"的假设被打破 → 算法失效。
```

### 3.3 Floyd 的 k 为什么必须在最外层？

```
Floyd 的含义：g[i][j] = 只经过 {1,2,...,k} 这些中间节点的 i→j 最短路
从小到大扩展 k——k 在最外层代表"逐步解锁中间节点"。

如果把 k 放内层：某些路径会用到尚未计算好的中间结果。
```

### 3.4 拓扑排序的存在条件

> **结论**：有向图能拓扑排序 ⇔ 图是 DAG（无环）。

所以拓扑排序本身就是**判环工具**——如果队列空了还有节点没入队，说明有环。

### 3.5 DAG 上的 DP

> **结论**：在 DAG 上，按拓扑序做 DP 可以求最长/最短路径、路径计数等。

你在 P4017 食物链做的就是 DAG 上的 DP：
- 入度=0 的点是起点（生产者），dp=1
- 按拓扑序转移：`dp[v] = (dp[v] + dp[u]) % MOD`
- 出度=0 的点是终点（顶级消费者），答案 = Σ dp[出度=0]

### 3.6 连通分量 vs 强连通分量

```
无向图：连通分量（connected component）— 互相可达的最大子图
有向图：强连通分量（SCC）— 有向图中互相可达的最大子图
```

B 组基本只考无向图。如果碰到有向图的 SCC，那是 Tarjan/Kosaraju 的范畴（在放弃清单里）。

## 四、数论和组合数学的"隐藏前提"

### 4.1 模运算的性质

```
(a + b) % m = ((a % m) + (b % m)) % m
(a - b) % m = ((a % m) - (b % m) + m) % m    ← 注意 +m 防负数！
(a * b) % m = ((a % m) * (b % m)) % m
(a / b) % m ≠ ((a % m) / (b % m)) % m         ← 除法不能直接取模！
```

**除法的替代方案**：乘以"乘法逆元"，即 `(a / b) % m = a * inv(b) % m`（当 m 是质数时，`inv(b) = b^(m-2) % m`，费马小定理）。

> 2024 国赛 G 题（数星星）就用到了组合数 + 逆元。

### 4.2 约数个数的公式

```
如果 n = p₁^a₁ × p₂^a₂ × ... × pₖ^aₖ（质因数分解）

则 n 的约数个数 d(n) = (a₁+1) × (a₂+1) × ... × (aₖ+1)
n 的约数和 σ(n) = (1+p₁+...+p₁^a₁) × ... × (1+pₖ+...+pₖ^aₖ)
```

你在 P1403 约数研究里暴力 O(n) 统计，其实也可以用这个公式 O(√n) 算单个数的约数个数。

### 4.3 组合数的两个视角

```
C(n, k)：从 n 个物品中选 k 个的方案数

两种常用递推：
① 杨辉三角：C[n][k] = C[n-1][k-1] + C[n-1][k]（你在 P2822 里用的）
   含义：固定选第 n 个 + 固定不选第 n 个
② 阶乘形式：C(n, k) = n! / (k! × (n-k)!)
   配合逆元可以 O(1) 查询（预处理阶乘后）
```

### 4.4 Dilworth 定理（你在 P1020 导弹拦截里用过）

> **Dilworth 定理**：偏序集的最少链划分数 = 最长反链长度。

在 P1020 中：
- 导弹高度序列，要求最少的不上升子序列数
- = 最长上升子序列长度（反链）
- 你第二问的 LIS 就是这定理的结论——但你可能不知道它叫 Dilworth

## 五、位运算的那些"黑话"

### 5.1 基础操作

```
x & 1         → 判断奇偶（1=奇，0=偶）
x >> 1        → x / 2（向下取整）
x << 1        → x * 2
x & (x-1)     → 消去最低位的 1（判断 x 是否为 2 的幂：x & (x-1) == 0）
x & -x        → 取出最低位的 1（= lowbit(x)）
x ^ x         → 0（自己异或自己 = 0）
x ^ 0         → x
```

### 5.2 异或的性质（比你想象的常用）

```
交换律：a ^ b = b ^ a
结合律：(a ^ b) ^ c = a ^ (b ^ c)
自反性：a ^ a = 0
恒等性：a ^ 0 = a

推论：如果 a ^ b = c，则 a ^ c = b，b ^ c = a
→ 给定两个值可以唯一确定第三个
```

2021 年国赛 J 题（异或三角）就大量用到异或性质。

### 5.3 状态压缩（状压）的基本思想

```
用二进制每一位代表一个元素是否被选：
  mask = 0b10101 → 选了第 0、2、4 个元素

操作：
  选第 i 个：mask | (1 << i)
  取消第 i 个：mask & ~(1 << i)
  判断第 i 个是否选：mask & (1 << i)
```

> B 组状压 DP 偶考（2016 生成树计数），了解基础即可。

## 六、单调栈和单调队列——你不一定知道什么时候用

### 6.1 单调栈的使用场景

**特征**：找每个元素**左边/右边第一个比它大/小的元素**。

典型题目：
- 直方图中最大矩形面积
- 每日温度（找下一个更高温度的天数）

**口诀**：遇到"下一个更大/更小"→ 单调栈。

### 6.2 单调队列的使用场景

**特征**：滑动窗口内的最大/最小值。

典型题目：
- 长度为 k 的滑动窗口，每次输出窗口内最大值
- 2024 国赛 H 题（套手镯）就用到了滑动窗口

### 6.3 两者的区别

```
单调栈：处理"往左看/往右看，第一个比当前值大/小的"
单调队列：处理"固定长度的滑动窗口内最值"
```

## 七、STL 中容易不知道但很常用的东西

### 7.1 set / map 的内部结构

```
set / map 底层是红黑树（平衡二叉搜索树）
→ 插入、删除、查找都是 O(log n)
→ 元素自动排序
→ lower_bound / upper_bound 也是 O(log n)

unordered_set / unordered_map 底层是哈希表
→ 插入、删除、查找均摊 O(1)
→ 元素无序
→ 不能做 lower_bound
```

### 7.2 lower_bound / upper_bound 的精确含义

```cpp
lower_bound(begin, end, x)  → 第一个 >= x 的位置
upper_bound(begin, end, x)  → 第一个 > x 的位置

// 求等于 x 的元素个数：
upper_bound(...) - lower_bound(...)

// 求 < x 的元素个数：
lower_bound(...) - begin
```

### 7.3 `pair` 的比较规则

```cpp
pair<int, int> a = {1, 5}, b = {1, 3};
a > b  // true，因为先比 first（相等），再比 second（5 > 3）

// 这为什么重要？Dijkstra 的优先队列是 pair<int,int>（距离, 节点）
// 先按距离排序，距离相同时按节点编号——这是正确的
```

## 八、容易忽视的复杂度常识

### 8.1 各复杂度能过什么数据范围（C++，1s 时限）

```
O(log n)    → n 随便多大
O(√n)       → n ≤ 10¹⁴
O(n)        → n ≤ 10⁸
O(n log n)  → n ≤ 10⁶
O(n√n)      → n ≤ 10⁵
O(n²)       → n ≤ 5000
O(n² log n) → n ≤ 2000
O(n³)       → n ≤ 500（Floyd 的上限）
O(2ⁿ)       → n ≤ 25
O(n!)       → n ≤ 11
```

### 8.2 空间复杂度

```
int a[10⁷]     → 约 40MB（int 4 字节 * 10⁷ = 40MB）
int a[5000][5000] → 约 100MB（太大！n=5000 的二维数组会 MLE）

一般题目内存限制 256MB，所以：
  一维数组：n ≤ 5×10⁷
  二维数组：n ≤ 10⁴（n×n ≤ 10⁸ 个元素 → 400MB 太大了）
           通常 n ≤ 5000 是二维数组的安全上限
```

## 九、"一题多解"中不同数据结构的取舍

同一个问题可以用不同数据结构，选哪个取决于操作类型：

| 需求 | 选什么 | 理由 |
|------|--------|------|
| 只查前缀和，不修改 | 前缀和数组 | O(1) 查询，最简单 |
| 只查区间最值，不修改 | ST 表 | O(1) 查询，建表 O(n log n) |
| 单点改 + 区间求和 | 树状数组 | 代码短，常数小 |
| 区间改 + 单点查 | 差分 + 树状数组 | 树状数组维护差分 |
| 区间改 + 区间求和 | 线段树 | 树状数组做不到 |
| 动态加点 + 全源最短路 | Floyd 逐 k | Floyd 天然支持 |
| 动态加边 + 连通性 | 并查集 | 只支持加边不支持删边 |

## 十、"板子之外"的思维模型

### 10.1 逆向思维

```
正向：求满足条件的最大值 → 二分答案（你熟悉了）
反向：正难则反 → 补集思想
  - 求"至少一个" → 1 - "一个都没有"（容斥）
  - 求"满足条件" → 总数 - "不满足条件"
```

2020 质数行者（三维 DP + 容斥）就是补集思想。

### 10.2 预处理思想

```
很多"多次查询"的题，把答案提前算好存起来：
  - 素数筛 → 预处理所有素数
  - lg 数组 → 预处理所有 log₂ 值
  - 阶乘数组 → 预处理 n!
  - 前缀和 → 预处理区间和
  - ST 表 → 预处理所有 2^k 区间的最值

核心：用空间换时间。算一次，查多次。
```

### 10.3 离线处理思想

```
在线：来一个查询处理一个
离线：先把所有查询读进来，排序/分类后统一处理

Floyd 灾后重建就是离线：村庄按重建时间排序，查询也按时间排序
→ 从小到大解锁村庄（= Floyd 逐 k 解锁中间节点）
```
