### B组核心结论

1. **DP是三语言共同的第一考点**（24-27%），无论选哪个语言都要重点准备
2. **C++ B组图论+数据结构更多**（共15%），大数据量图论和线段树在C++中更常见
3. **Python B组数论+字符串更多**（共26%），充分利用了Python的大整数和字符串API优势
4. **Java B组与C++ B组最接近**，但图论和几何略少，偶尔出现博弈题
5. 选语言不要基于"算法分布差异" — 差异在5%以内。选你最熟练的语言。

### 三组算法画像

```
A组: DP(26%) + 图论(13%) + 数据结构(8%) = 47%   ← 三大硬核算法撑起半边天
B组: DP(27%) + 搜索(15%) + 模拟(15%) = 57%      ← 均衡分布
C组: 模拟(26%) + 搜索(18%)           = 44%      ← 基础算法近一半
```

### 核心差异

| 维度 | A组 | B组 | C组 |
|------|-----|-----|-----|
| 难度锚定 | ACM 铜牌~银牌 | ACM 入门 | B组省赛水平 |
| DP 深度 | 树形/状压/数位DP 常规 | 背包/线性/LIS 为主 | 仅基础背包 |
| 图论深度 | 网络流/SCC/二分图 | Dijkstra/Kruskal/LCA | BFS/DFS/并查集 |
| 数据结构 | 线段树/主席树/平衡树 | 并查集/树状数组 | 数组栈队列 |
| 送分题比例 | 9% | 15% | 26% |

## 五、跨语言题目重叠度（关键发现）

| 对比 | 重叠率 | 说明 |
|------|:-----:|------|
| C++ B组 ↔ Java B组 | ~38% | 2016-2019几乎完全不同，2020-2021高度重叠(80%)，2022分化(10%)，近年40-50% |
| C++ B组 ↔ Python B组 | ~36% | 2021重叠80%，2022/2025几乎完全不同(0%/13%) |
| Java B组 ↔ Python B组 | ~45% | 两者共享的题比各自与C++共享的略多 |

**关键洞察**：
- **不同语言同组别的题目并非"翻译版"**，平均仅约 38% 重叠
- 重叠度**逐年剧烈波动**（0% ~ 80%），取决于当年命题策略
- 这验证了"**Java/Python必须独立调研，不能从C++推算**"

## 六、数据来源与方法论（v2.0）

### 真实数据来源

| 数据层级 | 组别 | 来源 |
|----------|------|------|
| **逐题验证** | C++ B组、Java B组、Python B组 | CSDN各届题解、洛谷收录题(P8xxx/P12xxx)、DashOJ/dotcpp OJ、博客园RioTian题解汇总、AcWing题解、知乎专栏 |
| **部分验证** | C++ A组(2016-2019)、C++ C组(2013-2021) | 博客园RioTian/CSDN题解、dotcpp OJ、E-COM-NET汇总 |
| **估算为主** | Java A/C组、Python A/C组 | 基于已知题目 + C++同组数据 + 语言特性调整 |

### 调研方法

1. **全网关键词检索**：以"蓝桥杯 + 国赛/决赛 + 语言 + 组别 + 年份 + 真题/题解"组合搜索
2. **多平台交叉验证**：CSDN、博客园、洛谷、AcWing、知乎、dotcpp、DashOJ、GitHub
3. **逐年逐题归类**：每道真题标注核心算法类别（一道题可能涉及多个类别）
4. **频次统计**：按算法大类汇总各年出现次数，计算占比
5. **跨组对比**：找出完全相同/相近/独有题目，计算重叠率

### 局限性

- **A组/C组数据不完整**：参赛人数少，公开题解少，部分年份仅有零星题目
- **早期年份（2016前）**：Java 和 Python 组的早期数据极其稀少
- **算法标注主观性**：一道综合题可能涉及多个算法，我们按"主要考查点"标注，存在一定主观判断
- **Python/Java A组**：这些组别的频次数据是目前可信度最低的部分，建议直接查阅蓝桥杯官方题库
- **2025届**（第十六届）：国赛缩至8题/组，数据较新，部分题目信息来自参赛者回忆

## 七、给不同人群的选组建议

| 背景 | 推荐 | 理由 |
|------|------|------|
| 985/211 本科 | C++ A组 | A组别无选择，C++运行效率最高 |
