## 算法分布特征（总结已有零星数据后的判断）

Java A组与 C++ A组在**算法类别分布上高度相似**（同组别、同难度档），差异在于：

| 方面 | Java A组特征 |
|------|-------------|
| **核心算法** | DP + 图论 + 数据结构（与 C++ A组相同） |
| **高级考点** | 线段树、网络流、状压DP、LCA（难度等同C++ A组） |
| **语言差异** | Java `BigInteger` 高精度题有优势；大数据量图论可能超时 |
| **独有题** | 约 30-40% 题目与 C++ A组不同（Java组会替换部分涉及指针/内存操作的题） |
