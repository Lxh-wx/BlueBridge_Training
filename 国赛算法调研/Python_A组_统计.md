## 算法分布（估算）

Python A组的算法覆盖面应与 C++ A组对标（同属A组难度档），但有以下调整：

| 调整方向 | 原因 |
|----------|------|
| 图论 -2 | Python 大数据量图论性能不足，命题会回避 |
| 字符串 +2 | Python 字符串处理API丰富，命题倾向于此 |
| 数论 +1 | Python 大整数 + math库天然优势 |
| 数据结构 -3 | 高级数据结构 Python 实现困难且易超时 |
| 几何 -1 | Python 几何计算效率劣势 |

## 选组建议

- **不建议**选 Python A组（除非你是 Python 铁粉且学校在985名单内）
- Python A组参赛人数极少 → 获奖率理论上高 → 但准备资源极少 → 备考困难
- 如果学校允许，选 C++ A组或 Java A组备考资源丰富得多
