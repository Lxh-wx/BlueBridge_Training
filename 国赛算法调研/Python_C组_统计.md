## Python C组 特征

C组的 Python 语言优势最大：
- `itertools.permutations` → 全排列题一行搞定
- `collections.Counter` → 频率统计
- `math.gcd` / `math.comb` → 数论题速通
- `bisect` → 二分一行
- `datetime` → 日期题比 C++ 方便 10 倍
- 速度问题在 C组基本不突出（数据量小）

## 选组建议

- **最佳冲奖组**：Python C组是 9 个组别中**竞争压力最小**的组
  - 参赛人数少（Python + C组双缩小）
  - 题目简单（C组难度 + Python语法优势）
  - 适合 Python 入门 3-6 个月的学生冲击国二/国三
- 但备考资源最少，需要参考 C++ C组的题目来练习

---

## 核心备考建议

1. 基础算法（枚举/模拟/贪心）→ 必须熟练
2. 基础 DFS/BFS（迷宫/全排列）→ 必须熟练
3. 基础 DP（01背包/完全背包/简单线性DP）→ 高分关键
4. 善用 Python 标准库（itertools/collections/math/bisect）→ 降维打击
5. 不需要学线段树/KMP/Tarjan → C组不考
