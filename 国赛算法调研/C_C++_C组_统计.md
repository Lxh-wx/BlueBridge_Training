## C组算法画像总结

| 算法维度 | C组特征 |
|----------|----------|
| **送分题**（模拟/枚举） | 占比最高（26%），年均 2-3 题纯暴力可过 |
| **核心得分**（搜索+DP） | 搜索(18%) > DP(13%)。DP以基础背包为主，不考复杂DP |
| **数论** | 基础素数、GCD/LCM、约数分解，不涉及高深数论 |
| **图论** | 仅BFS/DFS/并查集，不考Dijkstra/Kruskal/LCA |
| **数据结构** | 仅数组/栈/队列基本操作，不考线段树/树状数组 |
| **字符串** | 简单处理（拼接/反转/计数），不考KMP/AC自动机 |
| **几何** | 10年仅1题左右，几乎可以忽略 |
| **位运算** | 偶尔出现在填空/简单判断中 |

## C组备考重点

### 稳拿分（必会）
- 暴力枚举（全排列、多重循环）
- 模拟（日期处理、进制转换、过程模拟）
- DFS/BFS 基础（迷宫、全排列回溯）
- 基础DP（01背包、完全背包、简单一维DP）
- GCD/LCM、素数判定

### 冲击高分（选学）
- 二分答案
- 一维前缀和
- 并查集
- 简单贪心

### 不需要学
- 线段树、KMP、Tarjan、LCA、网络流、状压DP、AC自动机
- 这些在C组不会出现

## 与 B组的关键差异

| 维度 | C组 | B组 | 差距 |
|------|-----|-----|:--:|
| 模拟/枚举占比 | 26% | 15% | +73% |
| 搜索占比 | 18% | 15% | +20% |
| DP 占比 | 13% | 27% | -52% |
| 图论深度 | BFS/DFS | Dijkstra/Kruskal/LCA | 降2档 |
| 数据结构 | 数组栈队列 | 并查集/树状数组 | 降2档 |
| 整体难度 | ≈ B组省赛 | ≈ A组省赛 | 差1.5档 |
