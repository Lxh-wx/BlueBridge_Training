## A组独有/高频考点

| 考点 | 说明 |
|------|------|
| **线段树/主席树/可持久化** | A组常规考点，几乎每年1题升级 |
| **网络流（Dinic/ISAP）** | A组专属，B组不考 |
| **AC自动机** | A组字符串进阶专属 |
| **状压DP** | A组每年1题的概率很高 |
| **树形DP（复杂）** | A组比B组题目的DP更复杂 |
| **二分图匹配** | A组图论进阶 |
| **SCC/2-SAT** | Tarjan高级应用，A组常规 |
| **凸包/旋转卡壳** | 计算几何进阶 |

## 与 B组的关键差异

| 维度 | A组 | B组 |
|------|-----|-----|
| 模拟/枚举占比 | 9%（最少） | 15% |
| 数据结构占比 | 8%（最高） | 5% |
| 图论占比 | 13%（最高） | 10% |
| DP难度 | 树形/状压/数位DP 常规 | 背包/线性/LIS 为主 |
| 压轴题难度 | ACM铜牌~银牌 | 接近 ACM入门 |
| 独有考点 | 网络流/AC自动机/主席树 | — |

## 备考重点（A组国赛）

### 必须精通
- 线段树（区间修改、懒惰标记、可持久化）
- 树形DP + 状压DP
- LCA + 树上差分
- 网络流（Dinic板子）
- Tarjan全家桶（SCC/割点/割边/缩点）

### 涉猎即可
- AC自动机
- 二分图匹配（匈牙利算法/KM）
- 凸包（Graham/Andrew）
- 主席树/可持久化数据结构
- 后缀数组/后缀自动机

- 2016-2019年：博客园 RioTian 蓝桥杯国赛题解汇总 + CSDN 多源验证
