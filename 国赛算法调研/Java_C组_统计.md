## Java C组 特点

- 算法分布与 C++ C组高度相似（C组题目跨语言共用度最高）
- 不考线段树、KMP、Tarjan、Dijkstra等进阶算法
- Java `BigInteger`/`StringBuilder`/`TreeSet` 在基础题中有优势
- 竞争压力在9组中排倒数第二（仅高于Python C组）
- 非常适合编程基础一般的学生冲击国奖
