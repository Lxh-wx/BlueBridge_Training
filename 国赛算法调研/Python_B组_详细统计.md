> **数据来源**：全网检索各年 CSDN/博客园/知乎/AcWing/洛谷 Python 国赛真题题解，逐题归类
> **数据可信度**：⭐⭐⭐⭐（2020-2025共6年，均经多源交叉验证）
>
> **重要说明**：
> - Python 组国赛从 2020年（第十一届）开始设立，此前只有 C/C++ 和 Java
> - 2020年 Python 组为统一组别，2021年起逐渐分化 A/B/C 组
> - Python B组与 C++ B组的题目重叠度约 40-50%，且 Python 组有自己的特色题

### 与 C++ B组对比差异（Python B组特征）

| 差异点 | 说明 |
|--------|------|
| **字符串题更多** | Python 组的字符串处理题占比 ~10%，高于 C++ 组（~6%）。Python 的字符串API（切片、正则、Counter）天然优势 |
| **图论题更少** | Python 组图论仅 7%（4题），远低于 C++ 组 10%（9题）。大数据量图论 Python 运行效率是短板 |
| **数论题更多** | Python 组数论 16%，高于 C++ 组 12%。素数筛、GCD/LCM、大整数运算在 Python 中有语法优势 |
| **无高级数据结构** | C++ 组有线段树、树状数组；Python 组几乎不出现需要手写复杂数据结构的题 |
| **模拟题占比稍高** | Python 组模拟题 17% vs C++ 组 15% |
| **几何极少** | Python 组几何仅 1 题（三角形构造），C++ 组有 4 题 |

**核心结论**：Python B组的算法分布偏向"数学+字符串+DP"，回避大数据量图论和高级数据结构。整体难度比 C++ B组低半个台阶。

## Python B组特色考点

Python 语言特性带来独有的题型偏好：

| Python 优势 | 对应考点 | 频率 |
|-------------|----------|:----:|
| 字符串切片/正则 | 回文判断、子串处理、Counter | 每届 1-2 题 |
| 大整数原生支持 | 高精度计算、大数取模 | 每届 1 题 |
| math/statistics 库 | GCD/LCM/组合数 | 每届 1 题 |
| set/dict 天然哈希 | 去重、频率统计、查重 | 经常出现 |
| datetime 库 | 日期计算（比 C++ 方便得多） | 偶尔出现 |
| itertools | 全排列/组合枚举 | 偶尔出现 |
